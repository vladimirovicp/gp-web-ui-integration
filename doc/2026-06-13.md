# Отчёт: Текст без перевода

Дата: `2026-06-13`

## Суть проблемы

В проекте используется система переводов (`chain/js/locales/translations.js`, `en.js`, `ru.js`) с функцией `t('key.subkey')`. Однако в 20 файлах найден захардкоженный текст (русский и английский), который не проходит через `t()`. При смене языка этот текст останется без изменений.

### Приоритет исправления

1. **Высокий** — `preferences-template-shortcuts.js`, `preferences-table-shortcuts.js`, `preferences-view-template.js`, `preferences-template-common.js` — основной UI настроек, весь на русском
2. **Высокий** — `app.js` — модальное окно подтверждения
3. **Средний** — `chain.js`, `gpo.js` — уведомления (`IPA.notify`) не переводятся; label'ы сущностей могут переводиться через FreeIPA framework
4. **Средний** — `admx-template.js` — кнопки модального окна пакетов
5. **Низкий** — файлы-заглушки (`default-template.js`, `scripts-template.js`, 6 файлов `templates-*.js`) — временные сообщения
6. **Низкий** — `admx-controls-renderer.js` — плейсхолдеры для нереализованных элементов управления
